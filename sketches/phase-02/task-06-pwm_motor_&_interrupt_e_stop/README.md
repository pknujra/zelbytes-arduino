# Day 13 - PWM Motor Control and Emergency Stop System

## Objective

To control a DC motor using PWM through an L298N motor driver and implement an interrupt-driven Emergency Stop (E-Stop) system that immediately stops the motor and closes the irrigation valve.

---

## Hardware Used

* Arduino Uno
* L298N Motor Driver Module
* 12V DC Motor
* Relay Module
* Solenoid Valve
* Push Button (Emergency Stop)
* LED Indicator
* Jumper Wires
* 12V Power Supply

---

## Features Implemented

### PWM Motor Control

The motor speed is controlled through PWM signals generated by the Arduino and applied to the ENA pin of the L298N driver.

Speed can be adjusted through the Serial Monitor using commands.

### Relay-Controlled Valve

A relay module is used to safely control the solenoid valve.

Commands:

* `v` → Open Valve
* `c` → Close Valve

### Emergency Stop System

An interrupt-driven E-Stop button is connected to Arduino pin D2.

When activated:

* Motor stops immediately.
* Solenoid valve closes immediately.
* LED status indicator flashes continuously.
* System enters a locked state.
* Arduino reset is required to resume operation.

### Serial Commands

| Command | Function              |
| ------- | --------------------- |
| 0–9     | Set motor speed level |
| m       | Stop motor            |
| v       | Open valve            |
| c       | Close valve           |
| s       | Display system status |

## Wiring Connections

### L298N Motor Driver

| L298N | Arduino |
| ----- | ------- |
| ENA   | D5      |
| IN1   | D6      |
| IN2   | D7      |
| GND   | GND     |

### Relay Module

| Relay | Arduino |
| ----- | ------- |
| IN    | D8      |
| VCC   | 5V      |
| GND   | GND     |

### Emergency Stop Button

| Component | Connection   |
| --------- | ------------ |
| Button    | D2 ↔ GND     |
| Pin Mode  | INPUT_PULLUP |

### LED Indicator

| LED         | Arduino                   |
| ----------- | ------------------------- |
| Anode (+)   | D13                       |
| Cathode (-) | GND through 220Ω resistor |

## Safety Features

* Interrupt-driven emergency stop.
* Immediate motor shutdown.
* Automatic valve closure.
* System lockout after E-Stop activation.
* Relay isolation between Arduino and valve load.
* PWM speed limiting through software.
