# Day 2 - Git Repository Setup and Organization

## Objective

To establish a structured Arduino development environment using Git and GitHub for version control and project management.

## Work Completed

* Initialized a Git repository and configured a `.gitignore` file to exclude Arduino build artifacts.
* Created and organized the project folder structure for sketches, documentation, and wiring images.
* Added the Day 1 Blink sketch and made the first commit using a meaningful commit message.
* Documented the lab bench information and hardware inventory in `docs/HARDWARE.md`.
* Connected the local repository to a remote GitHub/GitLab repository and successfully pushed all project files.

## Learning Outcomes

* Gained hands-on experience with Git version control.
* Learned repository organization and documentation practices.
* Practiced creating meaningful commits and pushing changes to a remote repository.
