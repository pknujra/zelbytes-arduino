# Day 1 - Arduino IDE Setup and Basic Programming

## Objective

To set up the Arduino development environment, verify board connectivity, and perform basic microcontroller programming tasks.

## Work Completed

* Installed Arduino IDE 2.x and the required USB drivers for board communication.
* Verified correct board and port selection through the Arduino IDE.
* Compared Arduino Uno and Nano boards, including pin configurations, regulator capabilities, and suitability for compact agritech enclosures.
* Uploaded the Blink sketch and verified onboard LED operation.
* Modified the LED pin configuration where required to match board-specific LED wiring.
* Created and tested a Serial Monitor "Hello" sketch at 9600 baud.
* Established the project workspace under the `zelbytes-arduino` repository and created the Day 1 documentation.

## Learning Outcomes

* Gained familiarity with the Arduino IDE development workflow.
* Learned how to configure boards and communication ports.
* Understood the differences between Arduino Uno and Nano hardware platforms.
* Acquired experience in uploading firmware and using serial communication for debugging and monitoring.
* Established a structured repository for firmware development and documentation.
